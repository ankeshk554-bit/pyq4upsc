# Published question bank

Replace `questions.csv` with your approved question bank using the same headers as CSV import. The header-only file is intentional: no uploaded or private content is published automatically.

Commit this file with the website. New visitors automatically load and cache it. The relative path works on GitHub Pages project sites. Existing browser banks take priority and are not overwritten by website updates; import the revised CSV to update an existing bank. Answers and notes remain associated with unchanged question IDs.

Everything in this CSV will be publicly downloadable. Publish only content you have permission to distribute. This file contains questions only, never API keys or personal progress.
